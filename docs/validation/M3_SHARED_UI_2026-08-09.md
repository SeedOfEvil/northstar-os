# M3 shared UI acceptance — 2026-08-09

## Scope

This record closes the shared Lunar UI and first-party window-chrome slice on
the `codex/m3-shared-ui-chrome` branch. The slice introduces the reusable
`Northstar.Ui 1.0` QML module and applies its frame, title bar, controls,
palette, icons, native movement, and native resizing to Files, Settings,
Software Center, Welcome, and Text Editor.

## Automated evidence

- A clean FreeBSD build from an isolated checkout completed successfully on
  NSTAR-DEV01.
- The complete Qt/offscreen gate passed: 18 of 18 CTest targets.
- The QML surface contract and native build were rerun after the two manual
  acceptance fixes and remained green.
- The accepted build was installed into `/home/northstar/.local` before the
  final noVNC retest.

## Manual 1280x800 noVNC acceptance

The NSTAR-DEV01 Proxmox scfb/pixman development lane confirmed:

- Files, Settings, Software Center, Welcome, and Text Editor move reliably.
- Shared minimize, maximize/restore, close, and resize affordances work.
- First-party content remains usable without clipping at 1280x800.
- Software Center controls and both shell appearance themes remain functional.
- Text Editor presents one document title rather than duplicated title chrome.
- Dock Trash opens on the first click, including after its Files window was
  minimized or previously active.

The duplicate Text Editor title and second-click Trash regressions were found
during acceptance, corrected in the branch, redeployed, and explicitly
confirmed fixed on 2026-08-09.

## Deferred hardware evidence

This validates the supplemental Proxmox scfb/pixman lane only. Direct DRM/KMS,
GPU rendering and effects, multi-display behavior, and physical Intel/AMD
hardware acceptance remain separate release gates.
